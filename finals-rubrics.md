# Web Development Final Project Rubrics (100 points)

| Criteria | Description | Points |
| :--- | :--- | :--- |
| **1. Customer Mobile App Integration** | Mobile app successfully consumes the Customer API; smooth navigation and responsive mobile UI/UX; core customer features are functional end-to-end. | 15 pts |
| **2. Customer API Development** | At least 5 fully functional RESTful endpoints for customer operations (e.g., products, bookings, orders, profile, payments); follows proper HTTP methods and standardized JSON responses. | 15 pts |
| **3. Authentication & Security** | Secure authentication for customers (JWT/OAuth/session-based); protected routes; proper password handling and validation; sensitive data is secured. | 15 pts |
| **4. Role-Based Access Control (RBAC)** | Clear separation of permissions for Customer, Staff, and Admin roles; unauthorized access is properly restricted both in UI and API. | 10 pts |
| **5. Mobile & Web Synchronization** | Changes made in the mobile app reflect correctly in the web dashboard/database in real time or near real time; consistent data handling across platforms. | 10 pts |
| **6. Database Design & Data Management** | Well-structured relational/non-relational database; proper relationships, validation, and CRUD operations; avoids redundant or inconsistent data. | 10 pts |
| **7. Error Handling & Validation** | User-friendly validation and error messages on both Web and Mobile; API returns proper status codes and error responses; edge cases handled properly. | 10 pts |
| **8. UI/UX & Branding Consistency** | Professional and consistent design across Web Admin Panel and Mobile App; intuitive navigation; layouts adapt properly on different screen sizes. | 5 pts |
| **9. Deployment & System Stability** | Web app, API, and database are properly deployed or runnable in production-like setup; minimal bugs/crashes during demonstration. | 5 pts |
| **10. Documentation & Project Presentation** | Complete API documentation (routes, request/response samples); installation/setup guide; clear and organized final project presentation/demo. | 5 pts |
| **Total** | | **100 pts** |
